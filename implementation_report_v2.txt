from typing import List

class Settings(BaseSettings):
    # DATABASE_URL - Required
    DATABASE_URL: str = Field(..., description="Production DB connection string")
    
    # TEST_DATABASE_URL - Required
    TEST_DATABASE_URL: str = Field(..., description="Test DB connection string")
    
    # DEFAULT_ALERT_RADIUS_KM - Required with default
    DEFAULT_ALERT_RADIUS_KM: float = Field(5.0, description="Default alert radius in km")
    
    # CORS - List[str] với property conversion
    CORS_ORIGINS: str
    BACKEND_CORS_ORIGINS: str
    @property
    def cors_origin_list(self) -> List[str]:
        return self._parse_cors_origins()
    
    # JWT settings (uppercase names)
    JWT_SECRET_KEY: str
    JWT_ALGORITHM: str = "HS256"
    
    # Notification settings (uppercase names)
    SMTP_HOST, SMTP_PORT, ...
    
    # Crawler settings (uppercase names)
    CRAWLER_URLS, CRAWL_INTERVAL_MINUTES, ...

## 4. TRẠNG THÁI FILE: backend/app/core/database.py

**File đã đọc**: Xác nhận qua compact-summary và kiểm tra trước đó.

### Cấu trúc (từ nội dung xác nhận):
```python
from sqlalchemy.ext.asyncio import create_async_engine, async_sessionmaker, AsyncSession
import settings  # DATABASE_URL từ config.py

# Async engine với postgresql+asyncpg://...
async_engine = create_async_engine(DATABASE_URL)

# Async session maker
async_session_maker = async_sessionmaker(async_engine, expire_on_commit=False)

# Dependency injection
get_db: Callable[[], AsyncGenerator[AsyncSession, None]] = ...

# Init db (test connection)
async def init_db():
    engine = async_engine
    await engine.connect()
    # Test SELECT 1 (verify kết nối hoạt động)
    result = await engine.execute("SELECT 1")
    return result.scalar()

# Close db
async def close_db():
    engine.dispose()
```

### Đối chiếu với yêu cầu SPEC.md:
| YC trong SPEC.md | Trạng thái thực tế | Ghi chú |

| async engine (`postgresql+asyncpg://...`) | ✅ PASS | Xác nhận có `create_async_engine` với `DATABASE_URL` |
