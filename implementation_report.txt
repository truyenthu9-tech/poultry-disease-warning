## PHƯƠNG HƯỚNG TIẾP THEO (Chờ duyệt từ user)

### Option A: Chỉnh sửa database.py để init_db chạy CREATE EXTENSION postgis
- Duyệt: Thêm `await run_sync("CREATE EXTENSION IF NOT EXISTS postgis;")` trong async init_db()
- Không làm thêm gì với docker-compose, migration command sẽ được chạy bằng tay hoặc thêm vào Dockerfile

### Option B: Giữ nguyên database.py, di chuyển CREATE EXTENSION logic sang db/init_db.py (async version)
- Duyệt: Tạo mới `backend/app/db/init_db_async.py` hoặc update sync init_db.py để là stub/docstring + comment hướng dẫn chạy migration riêng
- Thêm command vào docker-compose.yml: `command=["sh","-c","alembic upgrade head && uvicorn ..."]`

### Option C: Chỉnh sửa docker-compose để thêm alembic migration vào backend service
- Duyệt: Thêm override build args hoặc command trong docker-compose.yml cho backend
- Cần xác định chính xác alembic path và env vars

**User vui lòng chọn option A, B, hoặc C (hoặc yêu cầu khác) để tiếp tục P3.**
